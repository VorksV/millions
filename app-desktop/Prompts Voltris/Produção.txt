🛠️ ETAPA CORRIGIDA: VOLTRIS UPDATER (SINGLE-FILE BLINDADO)
━━━━━━━━━━━━━━━━━━━━━━
O executável de atualização (VoltrisUpdater.exe) deve seguir um padrão de isolamento total para garantir que funcione em qualquer computador, mesmo sem o .NET Desktop Runtime instalado e sem dependências externas.

Para evitar crashes silenciosos (falta de wpfgfx_cor3.dll, D3DCompiler_47_cor3.dll, etc.), a compilação DEVE seguir estas especificações:

Isolamento de Arquitetura:
Gerar um VoltrisUpdater_x86.exe (contendo internamente o VOLTris_Optimizer_x86.zip).
Gerar um VoltrisUpdater_x64.exe (contendo internamente o VOLTris_Optimizer_x64.zip).
Flags de Compilação Obrigatórias:
PublishSingleFile = true
SelfContained = true
IncludeNativeLibrariesForSelfExtract = true 👈 Isso garante que todas as DLLs de vídeo/WPF sejam extraídas para uma pasta temporária e carregadas corretamente.
IncludeAllContentForSelfExtract = true 👈 Garante que o Payload (ZIP) seja visível para o motor de extração.
Configuração do Motor:
O Updater deve ser capaz de detectar se está rodando em modo Administrador e solicitar elevação se necessário.
Deve possuir tratamento de erro global com MessageBox para que o usuário nunca fique no escuro se o processo falhar.

Confirme que entendeu corretamente e, em seguida, descreva passo a passo como esse processo será executado, explicando claramente onde os arquivos ficam soltos e como são instalados.

E no final, compile e publique os updates das duas versões com os .zip compilados dos programas nas duas versões.
